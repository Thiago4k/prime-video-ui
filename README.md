# Prime Video Clone 🎬
Este projeto é um front-end inspirado fortemente na interface do Prime Video, desenvolvido para fins de estudo e prática de HTML, CSS e JavaScript com o auxílio do GitHub Copilot.

## Premissa 💡
O objetivo é simular a experiência de navegação do Prime Video, permitindo ao usuário escolher perfis, acessar um catálogo de filmes e séries, visualizar carrosséis de conteúdo e interagir com uma interface moderna e responsiva.

## Funcionalidades implementadas 🚀
* Tela de escolha de perfis: Usuário pode selecionar ou criar perfis personalizados, com armazenamento local das informações (nome e imagem) via localStorage.
* Catálogo dinâmico: O catálogo exibe filmes e séries organizados em categorias, com carrosséis horizontais navegáveis.
* Cards interativos: Cada conteúdo é apresentado em um card com imagem, nome, resolução, tags, breve descrição e acesso rápido ao trailer no YouTube.
* Barra de navegação: Menu superior com links para diferentes seções (Home, Filmes, Séries, Esportes, Infantil, TV ao vivo), simulando a navegação do Prime Video.
* Design responsivo: Layout adaptável para diferentes tamanhos de tela, com uso de Flexbox e estilização moderna.
* Armazenamento de progresso: O sistema pode exibir o progresso de visualização de cada conteúdo.
* Componentização em JS: Uso de módulos JavaScript para organização do código, incluindo componentes reutilizáveis como Card e Carousel.
* Acessibilidade: Elementos com atributos ARIA, navegação por teclado e foco visual.
* Personalização de perfis: Possibilidade de adicionar e remover perfis, com persistência local.
* Integração com trailers: Cada card possui link para trailer oficial no YouTube, extraindo automaticamente o ID do vídeo.
* Animações Fluídas: Uso de fadeIn com CSS Keyframes para entrada de elementos.
* UI Design: Paleta de cores baseada em Oxford Blue.

## 🚀 Como visualizar:
1. Tenha o VS Code instalado.
2. Use a extensão **Live Server** para rodar o projeto localmente.

# Prime Video Clone 🎬 (English)
This is a front-end project heavily inspired by the Prime Video interface, built for learning and practicing HTML, CSS, and JavaScript with the help of GitHub Copilot.

## Premise 💡
The goal is to simulate the Prime Video browsing experience, allowing the user to choose profiles, access a catalog of movies and series, view content carousels, and interact with a modern and responsive interface.

## Implemented Features 🚀
* Profile selection screen: Users can select or create personalized profiles, with local storage of information (name and image) via localStorage.
* Dynamic catalog: The catalog displays movies and series organized into categories, with horizontally scrollable carousels.
* Interactive cards: Each item is presented in a card with image, name, resolution, tags, short description, and quick access to the YouTube trailer.
* Navigation bar: Top menu with links to different sections (Home, Movies, Series, Sports, Kids, Live TV), simulating Prime Video navigation.
* Responsive design: Layout adapts to different screen sizes, using Flexbox and modern styling.
* Progress tracking: The system displays the viewing progress of each title.
* JS componentization: Use of JavaScript modules for code organization, including reusable components like Card and Carousel.
* Accessibility: Elements with ARIA attributes, keyboard navigation, and visual focus.
* Profile customization: Ability to add and remove profiles, with local persistence.
* Trailer integration: Each card has a link to the official YouTube trailer, automatically extracting the video ID.
* Smooth animations: Use of fadeIn with CSS Keyframes for element entry.
* UI Design: Color palette based on Oxford Blue.

## 🚀 How to run:
1. Ensure you have VS Code installed.
2. Use the **Live Server** extension to run the project locally.
